# The per-family-class path factor: decision on the milestone-4 data

Generated by `python scripts/vivado_m4.py refit`. Both candidates are the `vivado-2025.2-m4` refit (the `vivado-2025.2` points plus the two 20 ns post-synthesis rows); they differ only in whether Yosys/nextpnr gets one path factor or one per family class (FSM / pipelined; Vivado = 1 for both). Neither is the default.

## The rule (fixed before the 20 ns points were fitted)

Adopt it into the milestone-4 refit only if (a) Vivado Fmax leave-one-out RMS improves on the refit without it **and** (b) it puts `high_precision` m=8 infeasible and m=6 feasible at 50 MSPS (post-synthesis model throughput), as Vivado measures at 20 ns. Otherwise reject it.
